Esta operación elimina todas las reservas con estado cancelada cuya fecha de creación sea mayor a 30 días atrás.
Equivale a ejecutar en mongosh: 

db.reservas_comida.deleteMany({
  estado: 'cancelada',
  fecha_reserva: { $lt: new Date(Date.now() - 30*24*60*60*1000) }
})
